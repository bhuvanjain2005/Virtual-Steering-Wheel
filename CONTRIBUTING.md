# Contributing

Thanks for your interest in improving Virtual Steering Wheel!

1. Open an issue describing the bug or feature.
2. Include your Windows version, Python version, game, launcher, and input mode.
3. Create a branch for your change.
4. Keep changes focused and document new settings.
5. Test both gamepad and keyboard modes where possible.
6. Never commit `.venv`, personal data, screenshots containing private information, or driver installers.

Please do not submit changes that bypass a game's anti-cheat or violate its terms.
